# MakerWorld listings

Copy for each MakerWorld listing, ready to paste, one file per `makerworld/<name>.scad`. Every listing:

- turns on Customize with its script;
- is licensed CC BY-SA 4.0;
- stands on its own, and ends its description with one line pointing to hobbykit.app for what the Customizer cannot do. Write the address as plain text rather than a link: MakerWorld's guidelines forbid redirecting users off-platform, so the line must read as an extra, never as the real version being elsewhere;
- uploads the images from `just makerworld-images <name>` plus at least one photo of a real print, marked "Real life Photo". A real photo goes first as the cover; use the generated 3:4 cover for the Bambu Handy app.

Titles must match `LISTINGS` in `scripts/makerworldImages.ts`, which prints them on the covers.
