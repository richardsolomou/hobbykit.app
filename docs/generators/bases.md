# Magnetised miniature base generator

Make replacement, conversion, and display bases for tabletop miniatures, sized exactly and hollowed underneath to hold magnets.

## Footprint

Choose a round, oval, pill, rectangle, or regular polygon base, then pick a standard size or type exact dimensions. Presets follow Games Workshop's current Warhammer 40,000 and Age of Sigmar base size guides, The Old World, and Kings of War, and each names a few units that stand on it. Custom footprints from 15–180mm work too. Hex bases are measured across their corners, so they drop into the space of the matching round.

## Size label

The base's size is embossed inside, so a loose print still tells you what it is: a `28.5` base says `28.5`, not `29`. Type your own label instead, such as a unit name or squad number; text that cannot fit the base is reported rather than dropped, and the filename still names the size.

## Texture

Cut flagstones, cobblestones, hex tiles, square tiles, staggered planks, running-bond plates, herringbone bricks, or diamond plate into the face the model stands on. Planks, plates, and diamonds run along the base's longer side. Set the size of each stone, tile, or plank, which stays the same across every size in a batch, and how deep the joints go. That face is printed on the build plate, so every joint is a V whose sides stand at 45° and the stones print without supports. Joints run out through the edge, and the depth is capped to leave material above the recess. The preview shows these bases model face up so you can see the pattern, but they still print face down.

Rock, earth, rubble, sand, cracked earth, snow, and roots raise an uneven surface from the model face instead, up to 4mm high and out to the lip. A surface like that would need supports if it faced the build plate, so these bases print model face up and solid, with the magnet pockets opening on the underside and the size label engraved beside them. A solid base uses more filament than a hollow one, though the slicer's infill keeps it well under the solid weight shown. Relief prints in layers, so a finer or adaptive layer height in your slicer keeps its gentler slopes from stepping.

Every pattern except herringbone and diamond plate has a Variation, which rerolls its layout (the shuffle button picks one at random), and an Irregularity, which runs from tidy at 0% to wild at 100%.

## Magnets

Set the diameter, thickness, fit clearance, and depth clearance of the magnets you have. Each magnet sits flush with the face that meets a magnetised tray, and the depth clearance leaves room for adhesive behind it. The magnet count is recommended from the footprint and the magnet's size, or set it yourself for each footprint. Pockets follow a balanced arrangement or a five-pocket cross. Bases share their magnet settings with holders, movement trays, and spray trays, so every magnetised part lands on the same pattern.

## Underside

The underside is hollow, with supports that run out to every magnet pocket so each pocket prints as one connected feature. Adjust the bottom edge, wall thickness, top thickness, and the number and size of supports to suit your printer. The base prints with the face the model is glued to on the build plate, so every overhang points up and nothing needs supports.

## Batch export

Rebasing an army usually means several sizes at once. Add the current size to the batch as often as you need it, adjust each quantity, and download them together: STLs arrive as one archive with one file per size and its quantity in the name, while a 3MF keeps one object per size and lays out every copy across as many build plates as it needs. Every size in a batch shares the current base settings and follows its own magnet count. The batch is saved with your other settings.
