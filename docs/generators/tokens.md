# Tabletop gaming token generator

Make a round, square, or hex token for objectives, Oath of Moment, or anything else a game tracks. Every shape is sized across its flats: a round's diameter, a square's width, and a hex's flat-to-flat distance, so a 25.4mm hex fills a one-inch hex grid cell. Squares can round their corners. Type a word, a phrase, or a number and it wraps and scales to fill the face; drop in an image and its dark areas are traced into a silhouette, above the text when the token has both. Adjust the threshold or use the light areas instead to suit the artwork, then set the size, thickness, relief height, and top edge. Positive relief raises the text and image; negative relief engraves them into the face so tokens stack flat. Zero relief leaves a plain body. Raised artwork prints in a second filament: the 3MF, set up for a single-nozzle Bambu Lab P2S, puts the body on filament 1 and the artwork on filament 2; set its colour in the slicer. The artwork starts exactly on the top face, so the printer changes filament once; for a one-colour token, set both filaments the same in the slicer. The STL download has the body and the artwork as two files; load them together as one object with two parts. Engraved artwork stays one colour. Engraving always leaves at least 1mm of material beneath the artwork, and reducing the body thickness limits the depth to keep that floor. Tokens print flat on the table face with the artwork facing up, so nothing needs supports.
