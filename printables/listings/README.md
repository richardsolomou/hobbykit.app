# Printables listings

Copy for each Printables listing, ready to paste, one file per `makerworld/<name>.scad`. Printables has no online customizer, so every listing:

- uploads the ready-to-print STLs and the `.scad` that `just printables` writes into the git-ignored `printables/files/<name>/`, and names every one of them under Files;
- explains how to make other sizes in desktop OpenSCAD's Customizer;
- is licensed CC BY-SA 4.0, like the `.scad` it ships;
- keeps "Warhammer" out of the title and description, and ends the description with one plain line pointing to hobbykit.app;
- uploads the images under Images in that order, with the generated 4:3 cover as the cover, matching MakerWorld; the real photos come straight after.

Titles match the MakerWorld listings and `LISTINGS` in `scripts/makerworldImages.ts`, which prints them on the rendered covers.
